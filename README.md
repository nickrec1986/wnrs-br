# wnrs-br

This repo auto-publishes the Portuguese WNRS site at [wnrs.com.br](https://wnrs.com.br).

The site is built from [nickrec1986/wnrs](https://github.com/nickrec1986/wnrs) (`main`) with `npm run build:br`. A push to this repo, a manual workflow run, or the daily schedule checks out that source, builds `dist-br/`, and deploys it with GitHub Pages.

Content edits belong in [nickrec1986/wnrs](https://github.com/nickrec1986/wnrs), not here.
